# Protótipos experimentais

Estes arquivos são um registro parcial de desenvolvimento, fora do código compilado do repositório. Dependem de outras classes e recursos da cópia local; não são um mod instalável nem uma atualização ativa. A mineração em área das brocas está desativada. O XP do triturador ainda não foi implementado. As traduções contêm apenas as entradas das brocas. Não há teste no Minecraft. Leia docs/HAND_DRILLS.md e docs/crusher-xp-experiment.md antes de qualquer integração.
