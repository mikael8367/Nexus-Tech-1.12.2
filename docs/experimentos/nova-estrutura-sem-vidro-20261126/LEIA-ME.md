# Nova estrutura sem vidro — inspeção isolada, sem geração

Experimento para o anexo 6×5×7, **não** a estrutura anterior 10×8×8. O recurso em `src/main/resources/assets/nexustech/structures/nova_structure_sem_vidro.schematic.b64` é a representação Base64 do arquivo gzip NBT exato; o loader confere SHA-256 do binário decodificado `cf585cc66defdf94eb60c3fb17a313061937f5833da5dbc7703cd2dc4bfa1576` antes de lê-lo com NBT Minecraft 1.12.2. Este hash atesta apenas o recurso fixo decodificado, não a segurança de qualquer outra entrada. `inspect` recebe um NBT já analisado e não é validador geral de NBT hostil nem de DataVersion desconhecido; não oferece proteção geral contra entradas maliciosas ou suporte geral a NBT arbitrário. O original do usuário, mantido fora do repositório e não alterado, tem SHA-256 `eb23b1ec67c9ea74a974eb09fcbe7fcfe175f122b2a12aeb0b15513a740655cd`.

Comparação NBT real, offline: somente índice 168 mudou, ID numérico 20 para 0, metadata 0 para 0; todos os demais bytes dos arrays e demais tags NBT são idênticos. Estrutura final: 210 células, 119 IDs zero, 4 tiles: duas camas com color 14, fornalha com Items vazio, vaso com flor vermelha. Offsets WorldEdit [0,-5,0] são expostos sem aplicá-los; WEOrigin não é usado. Orientação somente identidade, ordem x+z*largura+y*largura*comprimento; inclui ar. Snapshot e tiles são cópias defensivas; não alteram ou instanciam tiles no mundo.

**IDs são numéricos e a ausência de um mapa de registros impede afirmar que são blocos vanilla.** Verifica ausência dos IDs numéricos 20,95,102,160, sob a hipótese de mapeamento vanilla. O ID vanilla 241 é terracota vitrificada rosa, não vidro, e é aceito. Essa checagem não comprova ausência de vidro modificado/remapeado; sem origem e mapeamento comprovados, não autoriza uso nem remoção adicional (fail-closed). Não se assume que um ID corresponde ao tile que o acompanha; validar compatibilidade no registro real antes de qualquer uso. A API não oferece rotação, posição mundial, escrita em chunk nem registro de gerador; recusa entidades não vazias. Nenhuma geração foi ativada. Sem backend seguro, sem prova em servidor Forge ou mundo, não usar em mundo.

Testes executados com javac Java 8 e classes Forge 1.12.2-14.23.5.2860 mapeadas preexistentes; sem Gradle e sem criar JAR. `NovaSchematicTest` cobre dimensões, limites, tipo/tamanho dos arrays, IDs 12-bit, metadados, IDs de vidro numéricos, duplicata/posição de tile, cópias, offsets parciais, ordenação e NBT do recurso. `CompareSchematic` compara o arquivo original com o recurso Base64 fixo: índice, IDs e metadata da mudança exigidos, todos os demais arrays e tags iguais. O teste compara cada uma das 210 células e os quatro NBTs completos dos tiles do snapshot com o original, além de testar cópias aninhadas e casos malformados. Esta execução isolada passou 1101 verificações e comparação integral do NBT; isso não representa teste real de inicialização Forge.

O repositório principal tem um projeto histórico também empacotado em ZIP; estes novos arquivos de origem/recurso no root não alteram ZIPs ou workflows existentes e não provam que um pipeline legado os incorpora em um JAR. Nenhum JAR deve ser gerado com este experimento.
